# Cloud 9 Wellness

## Live Website
https://cloud9wellness.pk/

## Project Overview
Cloud9 Wellness is a modern wellness and yoga platform designed to promote holistic health and well-being. The website provides information about yoga classes, wellness programs, teacher training courses, retreats, corporate wellness sessions, and online learning opportunities.

## Key Features
- Responsive and mobile-friendly design
- Wellness services and program showcase
- Yoga classes and teacher training information
- Corporate wellness solutions
- Retreats and events section
- Contact and inquiry forms
- Blog and content management
- SEO-friendly structure


## Technologies Used
- Laravel
- PHP
- MySQL
- Bootstrap
- JavaScript
- jQuery
